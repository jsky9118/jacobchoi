# Jacob Hanwool Choi, personal site

Static site for GitHub Pages. No build step.

## Put it online (about five minutes)

1. Sign in to GitHub and create a new public repository named `jacobchoi.github.io` (use your own username in place of `jacobchoi`; the name must be `<username>.github.io`).
2. Upload everything in this folder: `index.html`, `README.md`, and the `assets` folder with its five files. Keep the folder structure exactly as it is.
3. Open the repository’s Settings, then Pages. Under “Build and deployment,” choose “Deploy from a branch,” pick the `main` branch and the `/ (root)` folder, and save.
4. Wait a minute or two. The site is live at `https://<username>.github.io`.

## Updating

Edit `index.html` and upload it again. To replace the résumé, upload a new `assets/Jacob_Choi_Resume.pdf` with the same name.
